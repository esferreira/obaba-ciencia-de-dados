# 📘 Códigos do Livro: O B-A-BA da Ciência de Dados
### *Como Entender Dados, Interpretar Modelos e Decifrar a Inteligência Artificial*

Bem-vindo ao repositório oficial de códigos práticos do livro **O B-A-BA da Ciência de Dados**!

Este repositório contém todos os scripts Python organizados por capítulo, prontos para serem executados no seu computador local (via VS Code/Terminal) ou no **Google Colab**.

---

## 🚀 Como Usar Este Repositório

### 1. Clonar ou Baixar no Computador Local
```bash
git clone https://github.com/esferreira/obaba-ciencia-de-dados.git
cd obaba-ciencia-de-dados
```

### 2. Instalar as Dependências
Recomendamos criar um ambiente virtual antes de instalar as dependências:
```bash
# Criar ambiente virtual
python -m venv .venv

# Ativar ambiente (Windows)
.venv\Scripts\activate

# Ativar ambiente (Linux/Mac)
source .venv/bin/activate

# Instalar bibliotecas
pip install -r requirements.txt
```

### 3. Executar um Capítulo
```bash
python capitulo_01/01_verificar_ambiente.py
python capitulo_02/02_pensamento_logico.py
python capitulo_03/03_domando_tabelas_pandas.py
```
